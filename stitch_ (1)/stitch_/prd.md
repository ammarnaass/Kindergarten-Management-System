# وثيقة متطلبات تصميم التطبيق (Design PRD) — الإصدار المكتبي دون إنترنت
## تطبيق "روضتي" — Electron + Vite + SQLite + Drizzle

- **المنتج:** نظام إدارة روضة أطفال لسطح المكتب (Windows أولاً، ثم macOS / Linux)
- **النمط:** Offline-first — يعمل بالكامل دون اتصال بالإنترنت
- **اللغات:** العربية (افتراضي، RTL) + الفرنسية + الإنجليزية
- **المستخدمون:** الإدارة، السكرتارية، المعلمات، المحاسب
- **مبادئ التصميم:** الاعتمادية قبل كل شيء، السرعة محلياً، كفاءة المكتب ولوحة المفاتيح، مخرجات الورق والطباعة كجزء أساسي من التصميم.

### الشاشات الخمس الأساسية المحددة للتنفيذ:
1. **لوحة التحكم الرئيسية وإطار التطبيق (Dashboard & App Shell)**
2. **وضع الفصل وتسجيل الحضور السريع (Teacher Classroom Mode / Attendance)**
3. **المالية وتسجيل دفعة سريعة مع معاينة الإيصال (Payments & Receipts)**
4. **ملف الطفل الشامل مع التنبيهات الصحية وسجل التغييرات (Child Profile)**
5. **شاشة النسخ الاحتياطي والاستعادة وإدارة البيانات المحلية (Backup & Restore)**
